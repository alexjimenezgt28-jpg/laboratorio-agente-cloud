# laboratorio-agente-cloud

Laboratorio 12 de Tópicos Especiales II: delegación de una tarea de ingeniería a
un agente de desarrollo y revisión del resultado mediante rama y Pull Request.

## Contenido

- `tasks.py`: funciones para agregar, completar y listar tareas pendientes.
- `app.py`: demostración de uso.
- `tests/test_tasks.py`: pruebas con `unittest`.

## Ejecución

```bash
python app.py
python -m unittest discover -s tests -v
```
